# Hexora A&A — Business Decision System

A full-stack web app that helps small businesses keep their accounts in one place and get AI-generated suggestions from their own ledger data.

**Live demo:** https://hexora-blond.vercel.app

## Features

- **Google sign-in:** secure login with Google OAuth; each user sees only their own data
- **Account Groups and Account Master:** create groups (assets, liabilities, income, expenses, equity) and the ledgers under them, with opening balances and contact details
- **Ledger entries:** record sales, purchases, receipts, payments and journal entries, all stored in one ledger table
- **Dashboard analytics:** totals and trends calculated from your saved entries
- **AI business insights:** warnings, information and opportunities generated by the Gemini API, cached in the database, with a rule-based fallback if no API key is set
- **Profile setup:** company name, owner, support email, and toggles for automatic emails and fraud alerts

## Tech Stack

| Layer | Technology |
|---|---|
| Frontend | Next.js (App Router), React, TypeScript, Tailwind CSS |
| API | Next.js route handlers (`/api/accounts`, `/api/entries`, `/api/analytics`, `/api/profile` and more) |
| Auth | Auth.js (NextAuth v5) with Google OAuth |
| Database | PostgreSQL on Supabase, accessed through Prisma ORM |
| AI | Google Gemini API |
| Hosting | Vercel, deployed automatically from `main` |

## Project Structure

```
frontend/   Next.js app, Prisma schema, API routes (the deployed application)
backend/    Earlier FastAPI + SQLAlchemy prototype
```

## Run Locally

```bash
cd frontend
npm install
cp .env.example .env     # fill in the values, see SETUP.md
npx prisma migrate dev --name init
npm run dev
```

Open http://localhost:3000. Full environment variable details are in [`frontend/SETUP.md`](frontend/SETUP.md).
